# 日本語の用語・表記ルール

画面間で統一する用語や表記をまとめています。訳が揺れやすい用語を中心に記載します。

## 用語

| 英語                                    | 日本語           |
| --------------------------------------- | ---------------- |
| Sticky modifier keys / Sticky modifiers | 複合キー         |
| Modifier keys                           | 修飾キー         |
| Complex Modifications                   | 高度なキー変換   |
| Simple Modifications                    | 単純なキー変換   |
| EventViewer                             | イベントビューア |
| Multitouch Extension                    | マルチタッチ拡張 |
| expert                                  | エキスパート     |

## 表記ルール

- 日本語と英数字の間にスペースを入れません。
  例：`karabiner.jsonを編集`、`Webブラウザー`、`X軸`。
  `Magic Keyboard`のような英語名の中のスペースは維持します。
  `デフォルト: {value}`のように、半角コロン（`:`）の後にはスペースを入れます。
- 個々の複合キーの操作は、`fnを複合キーにする`のように表記します。
- 設定キー、ファイル名、`{count}`などのプレースホルダーは変更しません。
